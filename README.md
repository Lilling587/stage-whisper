# Stage Whisper

vill diskutera byggandet av en app som lyssnar på ljud och skriver det i text på en skärm. Så här är förutsättningarna: Det sitter tekniker på FOH och på scenen som pratar med varann via en intercomsystem. Denna konversation vill jag att appen lyssnar på och skriver som text på en skärm vid FOH och en skärm på scenen. Språket kommer att vara i huvudsak svenska. Detta eftersom det kan vara svårt att höra vad som sägs när det är hög ljudvolym ibland, och ibland måste tex ljudteknikern ta av sig sina hörlurar för att lyssna på vad som sägs i föreställningen
